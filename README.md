# simple-cookie-clicker: Cookie clicker but worse

## Code
Written in C (on CMake) with the SDL library. Uses dynamic linking.
## Building
On root, run the following commands:
- `cmake -S . -B build/`
- `cmake --build build/`

The executable should be in build/CookieClicker.exe.
